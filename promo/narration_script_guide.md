# 영상 C: 아카이브 사용법 (첫 사용 5단계, 약 70초) — 나레이션 대본

녹음: 줄 사이 0.5초 이상 쉬고 통으로 한 파일. 같은 목소리·속도(영상 A와 동일).

| 번호 | 장면 | 대사 |
|---|---|---|
| C-01 | 도입 | 보아코 아카이브, 어떻게 쓰는지 몰라서 망설였다면? 딱 다섯 단계면 끝나요! |
| C-02 | 1단계 로그인 | 첫 번째, 보아코 아카이브에 접속해서 카카오로 로그인! |
| C-03 | 2단계 닉네임 | 두 번째, 보드게임 아레나 닉네임을 입력해요. 보드게임 아레나에서 쓰는 닉네임과 똑같이, 정확하게! |
| C-04 | 3단계 기록기 | 세 번째, 기록기 설치! 위쪽의 기록기 설치 버튼을 눌러서 크롬 웹스토어에서 추가하세요. |
| C-05 | 4단계 게임 | 네 번째, 이제 보드게임 아레나에서 평소처럼 게임하세요. 게임이 끝나면 기록은 자동으로 저장돼요! |
| C-06 | 5단계 확인 | 마지막, 아카이브로 돌아와서 전적기록과 랭킹에서 내 기록을 확인하면 끝! |
| C-07 | 보너스 | 팀 창단이나 팀 목록에서 팀도 만들고, 팀 리그에도 도전해 보세요! |
| C-08 | 마무리 | 보아코 아카이브, 지금 바로 시작해요! |

## 영상 확정 전 확인할 사실
- 기록기 지원 브라우저 (크롬 웹스토어 버튼 외에 파이어폭스용 폴더도 있음)
- 게임 종료 후 "자동 저장"이 항상 동작하는지, 아니면 버튼을 눌러야 하는 경우가 있는지
- BGA 로그인이 되어 있어야 기록되는지
